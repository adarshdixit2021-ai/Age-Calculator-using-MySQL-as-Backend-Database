# 🎂 Age Calculator & Analytics (Full-Stack)

A modern full-stack web application with dynamic age analytics, zodiac detection, and persistent database storage.

## 🚀 Features
- **Accurate Analytics**: Calculates exact years, months, and days lived.
- **Astrological Insight**: Automatically detects Zodiac Sign.
- **Milestones**: Counts total days lived and days remaining until next birthday.
- **Persistent Storage**: Saves entry records directly into a MySQL database.
- **Cyberpunk Glassmorphism UI**: High-intensity fire burn hover animation and responsive dashboard layout.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3 (Glassmorphism & Keyframe Animations), Vanilla JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MySQL
